# apps

One host app per TypeScript runtime, all generated by `bun run build` (DO NOT EDIT anything but `xgen.app.json`):

| app | runtime | port | a screen |
|---|---|---|---|
| `host-svelte` | Svelte 5 | 5180 | `http://127.0.0.1:5180/<screen>/#/<route>` |
| `host-react` | React 19 | 5181 | `http://127.0.0.1:5181/<screen>/#/<route>` |
| `host-vue` | Vue 3 | 5182 | `http://127.0.0.1:5182/<screen>/#/<route>` |
| `host-solid` | SolidJS 1.9 | 5183 | `http://127.0.0.1:5183/<screen>/#/<route>` |

A landing, a theme or the block gallery is a screen spec in `xgen/specs/screens`, not an app.
`<screen>` is the screen id without `screen.`; `/` lists every screen. Dictionary, data, menus and runtime core: `packages/shared/app`.
