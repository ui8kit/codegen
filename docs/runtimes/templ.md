# Go templ

## Install

```bash
npx ui8kit@3 init --yes --framework templ --dir internal && npx ui8kit@3 add button
go get github.com/a-h/templ@<printed version> && templ generate && go build ./...
```

One Go package per primitive: `{dir}/ui/<brick>/` (`select` → package `selectfield`,
`switch` → `formswitch`), helpers in `{dir}/utils` (import rewritten to `<module>/<dir>/utils`
when `go.mod` exists). `*_templ.go` is generated by `templ generate`, not shipped. In this repo
the module is `github.com/ui8kit/codegen/generated/templ` (used by the doc snippets).

## Props and children

- Props are typed structs `<Part>Props` with canonical PascalCase fields (`Class`, `AriaLabel`,
  `For`); Select options are `[]selectfield.SelectOptionItem`.
- Children: `@button.Button(button.ButtonProps{...}) { … }` — rendered via `{ children... }`.
  Children are trusted markup: never pass user input through `templ.Raw` (XSS).
- Extra attributes: `Attrs: templ.Attributes{...}`.

## Deviations from React

- **Empty value**: blank strings omit the attribute, as in every runtime; `Value` is `*string`
  (`nil` = unset, `new("")` = `value=""`).
- **Attrs win**: a key in `Attrs` replaces the attribute the primitive would print (`uiutils.HasAttr`);
  `class` is the exception — use `Class`.
- **URLs**: unsafe schemes are omitted by `uiutils.SafeURL` / `uiutils.RestAttrs` (no
  `about:invalid#TemplFailedSanitizationURL`); `<img src>` allows `data:image/…` placeholders
  (`uiutils.SafeImgURL`). See [contract](../contract.md#attributes-precedence-empty-values-urls).
- No `asChild` / Slot.

## Helpers

`<Part>Classes(p <Part>Props) string`: `<a class={ button.ButtonClasses(button.ButtonProps{}) }>`.
