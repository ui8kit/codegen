# The public registry

ui8kit 2.0 is published as a shadcn-style registry: the CLI copies source files into an app.

| | |
|---|---|
| Docs and previews | https://ui.buildy.tw (source: [ui8kit/site](https://github.com/ui8kit/site), `generator/`, `content/`) |
| Registry roots | `https://registry.buildy.tw/<runtime>` for svelte, react, vue, solid, templ, twig, latte, jinja2 (`index.json`, `<type>/<name>.json`); all runtimes: `https://registry.buildy.tw/registry.json` (`contractVersion` 2.0.0) |
| CLI | [`ui8kit`](https://github.com/ui8kit/cli) on npm, 2.0.x: `init`, `add <name...>`, `add --all`, `list`, `diff`, `scan` / `build` |
| Item types | `registry:ui` (bricks = `src/primitives`), `registry:component` (`src/components`), `registry:block` (`src/blocks`), `registry:utils`, `registry:lib` |

```bash
npx ui8kit init --yes --framework svelte --dir src --registry-url https://registry.buildy.tw/svelte --strict-cdn
npx ui8kit add hero-split
```

## How the registry maps to this repository

The registry tooling of ui8kit/site (`registry/src/*.ts`, `@ui8kit/registry-tooling`) reads a source checkout given by
`--src` or `UI8KIT_SRC`:

| It reads | Here |
|---|---|
| `packages/<svelte|react|vue|solid>/ui/src/{primitives,components,blocks,utils,presets}` | generated by `bun run build` |
| `packages/<templ|twig|latte|jinja2>/ui` | generated |
| `packages/shared/app/src/{content.ts,runtime/core.ts,data/*}` | generated (previews: dictionary, `fromCodex`, fixtures) |
| `xgen/specs/blocks`, `xgen/specs/screens`, `xgen/specs/ui` (props tables) | specs |
| `xgen/screens/src/authoring/screens/themes.ts`, `apps/host-<rt>/xgen/screens/*` | builder and generated host screens (templates pages) |

The layout of this repository is the same as the codegen-x/ui8kit monorepo it was ported from, so the site can be built
from a public checkout instead of the private monorepo:

```bash
git clone https://github.com/ui8kit/codegen && (cd codegen && bun install && bun run build)
cd site && bun run registry:build -- --src ../codegen && bun run previews:build -- --src ../codegen && bun run templates:build -- --src ../codegen
```

Differences to expect today: this repository adds two bricks the registry does not list yet (`themetoggle`, `sheet`),
so a rebuilt registry will have 39 primitives per TypeScript runtime instead of 37; the 97 registry blocks are the 97
organisms of `src/blocks` (92 of them have a gallery block spec in `xgen/specs/blocks`).
